# 发现与分类筛选页设计

## 设计计划

遵循用户指定的 Codex 客户端方向：稳定的左侧导航和独立滚动的右侧内容，视觉重点留给真实番剧。第一屏以番剧精选为主，不引入数据大屏、播放统计或社区元素。

- 色彩：画布白 `#FFFFFF`、侧栏雾灰 `#F7F7F8`、正文炭灰 `#252628`、分隔线 `#E9E9EC`、状态鼠尾草绿 `#447467`；暗色切换为画布 `#202123`、侧栏 `#18191B`。完整 token 在 `packages/design-tokens`。
- 字体：系统 UI 字体优先，中文由苹方、Hiragino Sans GB、微软雅黑接替；品牌小标使用 Georgia。标题 26px、精选标题 32px、内容标题 17px，导航保持紧凑。
- 对齐：主要内容左对齐；宽屏海报六列，中屏三列，手机两列。主区最大 1240px，避免超宽显示器上信息过度分散。
- 形状：控件 6–8px、海报 10px、精选区 12px；只在弹窗和浮层使用明显投影。
- 动效：侧栏、交互反馈和海报轻微放大；横幅手动切换，无自动轮播。尊重 reduced-motion。

## 与需求的复核

保留 Codex 式浅灰侧栏、窄工具栏、灰阶选中态，撤去视频站常见的大面积主题色按钮和多层卡片边框。让精选番剧画面成为唯一大面积色彩，其余模块直接落在内容画布上。横幅使用作品名称和叙事短句，不将历年精选标注为当季热播。

## 顶栏与番剧目录

参考用户提供的 B 站客户端截图的布局关系，沿用 Hana 的系统字体、灰阶画布、鼠尾草绿强调色和原有海报组件，不引入 B 站的品牌、粉色选中态或会员标签。顶栏横跨窗口，左侧为侧栏开关与 Hana Logo，右侧为搜索和主题切换；侧栏不再含 Logo 或搜索。顶栏位于滚动容器之外，切换页面与滚动内容时始终可见。窄屏保留 Logo 小标，侧栏变为顶栏下方的抽屉。

番剧页使用 `#/anime`。筛选逐行左对齐，不包进多层卡片：排序、风格、年份、首播季度和评分；海报继续使用宽屏六列、窄屏两列。年份来自当前数据，未知日期和评分不会被推断。筛选仅作用于当前加载的一页，界面明确标注范围；地区、会员或付费条件暂无数据支持，不显示占位控件。

## 数据与行为

- 推荐：11 部人工选取的真实作品，Bangumi 资料快照。排序与类型筛选在共享领域层进行；元数据与海报源记录见 `artwork-sources.json`。
- 顶部全局搜索：从发现、资料库或播放页输入均进入番剧页；在小说、漫画页输入则搜索当前栏目；关键词写入 hash 参数 `q`，支持刷新与浏览器返回，连续输入不堆叠历史。清空搜索留在番剧页，新关键词重置筛选。`⌘/Ctrl + K` 聚焦顶栏搜索。
- 番剧目录：默认读取 Bangumi 高分列表的一页 24 部，搜索后展示搜索结果。风格、年份、季度、最低评分可组合筛选，支持重置和空结果恢复。失败明确回退到本地精选。
- 搜索：Bangumi `POST /v0/search/subjects`；350ms 防抖，取消旧请求。请求失败后只展示本地精选里匹配的条目，并明确标注。
- 高分：Bangumi `GET /v0/subjects?type=2&sort=rank` 获取一页 24 部条目，页面支持评分/年份排序；不是全站无限列表。
- 放送：Bangumi `GET /calendar`；真实星期分组，失败不伪造更新记录。
- 每次外部响应经过字段校验；忽略非动画条目，过滤明确标注的 NSFW 条目，限制图片为 HTTPS。海报加载失败显示标题占位。
- 追番：本地浏览器持久化，读取时校验结构和去重；存储不可用时提示会话状态。暂不提供账户同步。
- 番剧入口：点击卡片、标题或精选按钮跳转独立播放页。页内展示资料、来源、线路和该线路分集，详见 `playback.md`。观看历史仅记录实际播放。
- 可访问性：原生 dialog 焦点约束与 Escape 关闭、键盘标签页切换、焦点描边、跳过导航链接、按钮状态与反馈公告。

## 小说与漫画目录

- 新增 `#/novel` 和 `#/manga`，探索区按发现、番剧、小说、漫画、每日放送排列。本阶段只有目录与筛选，不包含书籍详情、阅读、收藏或阅读历史。
- 设计沿用既有画布白 `#FFFFFF`、侧栏灰 `#F7F7F8`、正文 `#252628`、分隔线 `#E9E9EC`、强调绿 `#447467`，暗色使用现有 token；系统中文字体、26px 页面标题、17px 结果标题、13px 卡片标题。布局为「标题 → 分行筛选 → 结果摘要 → 六列封面」，窄屏为两列。无新增视觉主题，保持与番剧页一致。
- 筛选行：排序、题材、出版年份、连载状态、评分。所有条件组合应用到当前返回的最多 24 部资料，并明确标注范围。年份来自实际数据，状态只取公共元数据；缺失值显示未收录，不从册数或不一致的用户标签推断完结。
- 使用独立的 `Book`、`BookRepository`、`useBooks` 和 `BookCard`；不将书籍转换为可播放的 `Anime`，不混入追番或观看历史。书籍卡片为资料展示，无未实现的按钮或跳转。
- 目录请求 Bangumi `GET /v0/subjects?type=1&cat=1002`（小说）或 `cat=1001`（漫画），按排名加载第一页。关键词搜索使用 `POST /v0/search/subjects`，限制 `type: [1]` 与对应的 `meta_tags`，在转换时再次校验 `platform`。拒绝异常 ID、类型不匹配和明确 NSFW 条目。
- 搜索框文案跟随栏目，关键词保存在 hash 的 `q` 参数中，刷新和返回可恢复。新关键词/切换栏目重置筛选；350ms 防抖、取消过期请求，失败提供重新加载，空结果可清除搜索与筛选。书籍无离线快照，失败不借用番剧填充。
- 元数据与远程封面均由 Bangumi 返回；未新增本地素材。字段及分类依据 [Bangumi v0 API](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)。
- 验证：书籍边界与组合筛选单测、栏目切换/搜索/刷新/失败恢复 E2E，以及亮暗色和手机宽度截图；真实接口检查与受控 E2E 分开记录。
