# 发现页设计与实现

## 设计计划

遵循用户指定的 Codex 客户端方向：稳定的左侧导航和独立滚动的右侧内容，视觉重点留给真实番剧。第一屏以番剧精选为主，不引入数据大屏、播放统计或社区元素。

- 色彩：画布白 `#FFFFFF`、侧栏雾灰 `#F7F7F8`、正文炭灰 `#252628`、分隔线 `#E9E9EC`、状态鼠尾草绿 `#447467`；暗色切换为画布 `#202123`、侧栏 `#18191B`。完整 token 在 `packages/design-tokens`。
- 字体：系统 UI 字体优先，中文由苹方、Hiragino Sans GB、微软雅黑接替；品牌小标使用 Georgia。标题 26px、精选标题 32px、内容标题 17px，导航保持紧凑。
- 对齐：主要内容左对齐；宽屏海报六列，中屏三列，手机两列。主区最大 1240px，避免超宽显示器上信息过度分散。
- 形状：控件 6–8px、海报 10px、精选区 12px；只在弹窗和浮层使用明显投影。
- 动效：侧栏、交互反馈和海报轻微放大；横幅手动切换，无自动轮播。尊重 reduced-motion。

## 与需求的复核

保留 Codex 式浅灰侧栏、窄工具栏、灰阶选中态，撤去视频站常见的大面积主题色按钮和多层卡片边框。让精选番剧画面成为唯一大面积色彩，其余模块直接落在内容画布上。横幅使用作品名称和叙事短句，不将历年精选标注为当季热播。

## 数据与行为

- 推荐：11 部人工选取的真实作品，Bangumi 资料快照。排序与类型筛选在共享领域层进行；元数据与海报源记录见 `artwork-sources.json`。
- 搜索：Bangumi `POST /v0/search/subjects`；350ms 防抖，取消旧请求。请求失败后只展示本地精选里匹配的条目，并明确标注。
- 高分：Bangumi `GET /v0/subjects?type=2&sort=rank` 获取一页 24 部条目，页面支持评分/年份排序；不是全站无限列表。
- 放送：Bangumi `GET /calendar`；真实星期分组，失败不伪造更新记录。
- 每次外部响应经过字段校验；忽略非动画条目，过滤明确标注的 NSFW 条目，限制图片为 HTTPS。海报加载失败显示标题占位。
- 追番：本地浏览器持久化，读取时校验结构和去重；存储不可用时提示会话状态。暂不提供账户同步。
- 番剧入口：点击卡片、标题或精选按钮跳转独立播放页。页内展示资料、来源、线路和该线路分集，详见 `playback.md`。观看历史仅记录实际播放。
- 可访问性：原生 dialog 焦点约束与 Escape 关闭、键盘标签页切换、焦点描边、跳过导航链接、按钮状态与反馈公告。

## 接口来源

- [Bangumi API 定义](https://github.com/bangumi/api/tree/master/open-api)
- [Jikan 文档](https://docs.api.jikan.moe/)：仅在开发时获取 MyAnimeList 海报地址；运行时不依赖 Jikan。
- [芙莉莲官方第一集剧照](https://frieren-anime.jp/story/1st/ep01/)：精选横幅。

所有番剧海报和官方剧照版权归原权利人所有，项目代码不改变其授权。素材为本地界面开发参考，商业发布前需确认相应使用权限。

## 验证命令

`pnpm check` 检查 TypeScript、共享逻辑测试和生产构建。`pnpm test:e2e` 用 Chrome 验证交互、窄屏、亮暗主题、收藏持久化及错误恢复。E2E 对第三方 API 使用可控响应，不能当作在线服务可用性保证。
